## Proposed decisions for review

Recommend one application and PostgreSQL database, explicit organizational authority grants, versioned records and requirements, private attachments, transactional decisions, caller-aware workflow instances and derived register/traveler views. Keep evolving engineering requirements in versioned definitions; keep Rev C routing explicit and covered by tests rather than exposing arbitrary route editing. No recommendation in this package is a user approval or a new QC requirement.
